# 搜索结果说明

适用范围：搜索成功后向用户呈现相似广告视频。必须依据 result.json 的真实返回值，不补造缺失数据。

## 工作流程

简要说明搜索范围和返回数量，按返回顺序展示游戏名称、相似度、预览或详情链接。用户需要时再补充开发商、投放平台和日期。表格或列表均可，不要求固定段落数量，也不加入与本次搜索无关的分析。

相似度是检索分数，不能据此认定素材归属或抄袭。字段缺失时标记未提供；活动状态和预估曝光按服务返回值展示，不推断为永久停投或真实广告支出。

当前一次最多返回 50 条。本脚本不支持翻页；有更多候选时如实说明，禁止编造分页参数。改变搜索条件可能消耗额外查询额度。

## 完成与验收

返回 items 才算获得搜索结果，空列表表示没有找到符合条件的素材；processing 表示仍在处理。只展示服务返回的有效 HTTP/HTTPS 链接。

禁止分享授权令牌、上传票据、授权链接参数或整个任务目录。用户需要文件时仅交付所需结果，诊断信息另行脱敏。

# 排障与续查

适用范围：对比查询失败、中断或授权异常时读取。处理原则是先看已有结果，再决定是否重试，避免重复消耗账号额度。

## 先检查再重试

脚本在查询前打印结果路径，并生成同名 `.attempt` 标记。

- 结果文件存在 → 直接读取复用，不重跑。
- 只有 `.attempt` 标记、没有结果文件 → 本次结果未确认，可能已消耗额度。先向用户说明，由用户决定是否重查，不自动重试。
- 提示 `OUTPUT_EXISTS` → 读取已保存结果，不覆盖、不重跑。
- 提示 `PREVIOUS_ATTEMPT` → 先检查上一次结果路径，确认状态后再操作。

## 常见错误

| 提示 / 现象 | 含义与处理 |
| --- | --- |
| `LOGIN_REQUIRED` | 未登录或授权过期。运行 `scripts/auth.py login` 完成浏览器授权后，用原参数重新执行。 |
| `AUTH_FAILED` | 授权流程未完成。确认浏览器已完成登录与授权，不重复打开登录窗口。 |
| `LOGIN_CANCELLED_OR_TIMED_OUT` | 用户取消或超过 10 分钟未完成。停止并询问用户，不自动重开。 |
| `TOOL_UNAVAILABLE` | 账号或服务未提供该工具。说明能力限制，不猜测接口。 |
| `REQUIRED_ARGUMENT_MISSING` / `UNKNOWN_ARGUMENT` | 参数与实时 schema 不符。按实时目录修正，不硬凑参数。 |
| `MCP_TOOL_ERROR` / `error_code` 非空 | 业务层错误。读取返回的错误信息向用户解释。 |
| `HTTP_401` | 授权失效，引导重新登录。 |
| `HTTP_403` | 权限不足或额度用尽，停止查询并解释。 |
| `NETWORK_ERROR` | 网络中断。保留结果路径，检查网络后再决定是否重试。 |
| `CURL_MISSING` / `CURL_7_70_REQUIRED` | 缺少 curl 或版本过低。说明缺项，取得同意再安装。 |

## 授权处理

同一系统用户的本包与其他橙果数航技能包共用自有授权存储，已有有效授权可复用。401 引导重新授权；403 或额度不足停止并解释；网络错误保留路径，不擅自关闭证书验证或更改代理。企业网络只允许代理时，由用户确认网络策略后再操作。

仅当用户明确要求退出时才运行 `scripts/auth.py logout`。这会撤销共享授权，其他技能包也需要重新登录。

# 橙果数航 海外游戏素材相似与复用

本 Skill 让助手基于一条素材详情链接，完成素材详情查询、相似广告检索和复用线索查找。用户只需提供素材详情链接和想问的方向；首次使用需本人在浏览器登录橙果数航（DataVoyage）并授权。助手负责执行脚本和整理结果。通过内置脚本直接访问橙果数航 MCP HTTP 服务，不依赖 WorkBuddy 连接器审核或安装。

## 必须遵守

- 必须使用本包脚本；禁止读取 WorkBuddy 或其他客户端的私有凭据缓存，禁止索取账号密码。
- 用户仅在官方浏览器页面登录。不得输出令牌、授权回调、缓存内容或完整授权 URL 到报告。
- 输入必须是本服务返回的完整 `detail_url` 并原样透传。禁止从普通视频地址、本地路径或截图猜测素材标识。
- 必须区分“记录的直接复用关系”和“内容向量相似”：相似分数不是同源概率，出现先后不是原创归属证明，禁止认定抄袭、素材所有权或因果关系。
- 每条结果保留自己的 `detail_url` 和可用 `media_url`，禁止拆解、拼装或交叉配对链接。
- 只执行用户请求所需的查询，不自动扩展日期范围，不为凑满条数无限翻页，不为诊断反复重试。

## 适用范围与环境

适用于“这条素材被哪些游戏用过”“找相似广告”“素材复用线索”“素材流向”。不适用于本地图片或视频上传检索（用图搜视频技能）、按条件筛选素材（用素材查询技能）、商店榜单查询，以及竞品投放量级对比。用户只提供本地文件或截图时，说明需要服务返回的素材详情链接，不擅自上传。

适用于 WorkBuddy 市场安装本技能后的使用：命令均相对于本 Skill 根目录，助手应自行定位安装目录，不依赖固定用户名或磁盘路径。

需要 Python 3.9+ 和 curl 7.70+。脚本只用 Python 标准库，无 pip 包、Node.js、ffmpeg 或 ffprobe 依赖。Windows 优先 `py -3`（没有时检测可用的 `python`）；macOS 使用 `python3`。缺少依赖时说明具体缺项，取得用户同意再安装，不要求新手配置 API Key、环境变量或连接器。

## 工作流程

1. 确认用户持有的素材详情链接，并识别想问的方向（素材详情 / 相似广告 / 复用线索）。已有信息足够就继续；没有链接时说明需要详情链接并解释获取方式，不接受本地路径。参数含义与现成示例见[查询指引](references/query-guide.md)。
2. 直接运行正式入口完成查询。脚本会自动完成工具发现、身份校验和参数核对，**不需要先单独执行 --catalog**（该模式仅用于诊断）。查询参数以内联 JSON 传入：

   Windows：`py -3 scripts/related.py --tool get_material_reuse_clues --args "{\"detail_url\":\"https://...\",\"limit\":10}"`

   macOS：`python3 scripts/related.py --tool get_material_reuse_clues --args '{"detail_url":"https://...","limit":10}'`

   参数较多或含特殊字符时，可把参数写为 UTF-8 JSON 文件后用 `--args-file query.json` 代替 `--args`；文件只含查询条件，不含凭据。

   三个工具的用法：`get_material_detail_v2` 取素材详情（按需传 `include: ["summary","media"]`，已有信息不重复获取）；`get_material_reuse_clues` 取复用线索（`limit` 默认 20、最大 50，单位为最多返回的游戏数）；`get_similar_materials_v2` 取相似广告（`date_from`、`date_to` 必填且跨度最大 180 天，`cross_game` 控制是否跨游戏，`sort_by` 用 `similarity`，`limit` 默认 10、最大 20）。日期未指定时使用截至服务当前日期的近 30 个自然日并告知用户。参数必须匹配实时 schema，脚本会拒绝缺失必填项和未知参数。
3. 仅遇到 `LOGIN_REQUIRED` 或身份验证失败时运行 `py -3 scripts/auth.py login`（macOS 用 `python3`），告诉用户“请在打开的浏览器登录橙果数航并授权，完成后我会继续查询”。登录进程最多等待 10 分钟：使用后台任务或足够长的执行窗口，保持进程存活。用户关闭或拒绝后停止，不反复打开浏览器。成功出现 `LOGIN_OK` 后用原参数重新执行入口命令。
4. 脚本在查询前打印结果路径并生成 `.attempt` 标记；超时或中断后先检查该路径。存在 result 文件就读取复用；只有标记没有结果时，说明结果未确认，不自动重试可能已计费的请求。输出路径已存在时按 `OUTPUT_EXISTS` 提示读取已保存结果，不重跑。
5. 用户同时需要多种结果时分别查询、分别呈现；一种没有结果不代表另一种也没有结果。读取脚本打印的 `output` 文件，先检查业务错误（`error_code`）与查询范围，再按[结果呈现](references/output-format.md)组织答案。失败或中断时按[排障与续查](references/troubleshooting.md)处理。

使用助手支持的长任务或后台进程机制定期查看进度，不能因单次工具等待上限结束就重启查询；网络、代理和服务器也可能提前超时，不承诺固定总耗时。

## 授权与失败处理

同一系统用户的本包与橙果数航其他技能包（素材查询、图搜视频、商店榜单、竞品投放对比）共用自有授权存储，已有有效授权可复用；不读取连接器登录状态。已有 MCP 授权不等于本包获得授权。缓存保存在系统用户应用数据目录，脚本限制本地访问权限，不要读取或展示缓存。已有 `AUTH_TOKEN` 环境变量时脚本优先使用它，但新手无需设置。

401 或登录失效时引导重新授权；403 或额度不足时解释账号权限问题并停止；网络错误时保留结果路径，检查用户网络后再决定是否重试，不自动更改代理或关闭证书验证。脚本默认直连官方服务，企业网络只允许代理时需由用户确认网络策略。工具缺失时说明账号或服务尚未提供能力，不猜测接口。

用户明确要求退出时执行 `py -3 scripts/auth.py logout`（macOS 用 `python3`）。这会撤销并删除共享授权，其他橙果数航技能包也需要重新登录；不会清除其他连接器缓存，也不会修改环境变量。

## 输出与验收

先说明结果类型（素材详情 / 相似广告 / 复用线索）、查询日期范围与是否跨游戏，再按类型分块呈现：

- **素材详情**：素材类型、所属游戏、投放信息与 `media_url`。
- **相似广告**：查询日期范围、关联游戏、相似度分数，以及每条对应的完整 `detail_url`。
- **复用线索**：关联游戏、开发商、首次与最后出现时间及代表素材。

输出必须区分“记录的直接复用关系”和“内容向量相似”，并说明相似分数不是同源概率、出现先后不是原创归属证明。保留可用 `media_url`，不输出孤立素材标识。无结果如实说明；查询失败不能伪装成没有相似或复用素材。

验收必须满足：查询范围与用户意图一致；每条链接对应同一条素材；多种结果分别呈现互不替代；不认定抄袭或素材所有权。完整回答用户所问的方向即完成，不扩展成长篇创意分析报告。
